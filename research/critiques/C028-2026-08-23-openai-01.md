## Falsification attempts

### 1. Enumeration-completeness attack

The generator covers all pair/singleton partitions, not merely the two desired
epsilon representatives. Singleton diagrams explicitly test `V.E`; eta-only
diagrams are generated and reduce to zero rather than being omitted. Wedge
canonicalization distinguishes `K_i` from `E_i`, kills only repeated identical
odd atoms, and its normalization outputs agree with the factorial orbit sizes.
The adapted-frame evaluation is legitimate because unit spacelike `V` is one
`SO(1,4)` orbit and the diagrams are covariant before evaluation. The reported
counts—ten diagrams plus epsilon, eleven candidates, one survivor and rank one
in each sector—match the code. The two-`K` rank-two control is a useful domain
boundary witness. **No class-exhaustion defect found under the frozen trusted
invariant-generator premise.**

### 2. Derived-variation attack

The decisive rows are not inserted into the varied expression: `graph()`,
`vary()`, and `ibp()` produce them from the generic root, after which marker
coefficients are extracted. `expected_rows()` is a distinct direct tensor
assembly, although it shares the same sparse algebra, epsilon routine, `pi`,
and covariant-derivative helper and is therefore a correlated comparison rather
than an independent route. Lorentz lowering in `delta K`, the minus corner,
coframe companion, transverse `V` row, and corrected Noether sign are all
represented. The five mathematical mutations for pair order, fiber sign,
coframe omission, premature `delta K=0`, and all-plus Noether grading alter an
upstream semantic choice and fail substantive assertions. **No scientific row
error found.**

One control is weaker than advertised: the
`undeclared-exact-ibp-quotient` child does not mutate the quotient semantics.
The API still rejects the forbidden relation, and line 270 simply registers a
literal false assertion when that mutation name is present. Its exit code is
therefore guaranteed rather than demonstrating that an undeclared quotient
would be detected downstream. The ordinary positive assertion does genuinely
test API rejection, so this weak mutation does not invalidate C028, but it
overstates the sixth mutation's evidentiary value.

### 3. Polar, elimination, and recorded-output attack

The polar assembly is separate from the rank path. It derives
`Pi43=-oSigma/2`, `Pi34=+oSigma/2`, uses both ordered connection components,
sets canonical `delta omega34=-delta chi43 dtheta`, and applies the extra minus
needed to move the fiber leg right. It reproduces
`tau(kappa5_inv-gamma)`, `-3 tau gamma c`, and `tau lambda`, with zero transverse

More seriously for the declared machine-support procedure, O015's frozen
