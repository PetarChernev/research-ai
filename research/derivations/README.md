# Derivations

Substantial derivations use stable IDs `D001`, `D002`, and so on. Copy `templates/derivation.md`, allocate the next unused ID, and keep notation, assumptions, exact steps, approximations, validity conditions, dimensional checks, and limiting cases in the artifact.

Allowed statuses are `draft`, `complete`, `checked`, and `superseded`. `checked` means the recorded checks were performed; it does not independently verify the target claim. Link derivation IDs from `research/claims/ledger.yaml`.
