## Reconstruction

### 1. Profile flatness and asymptotic ordering (independent from D002)

For any p > 0 and s > 0, define f(s) = exp(-(L/s)^p). Each derivative is a finite sum of
monomials of the form (polynomial in L/s) × exp(-(L/s)^p). Since every power of (L/s)
is dominated by the exponential as s ↓ 0, the function and all its derivatives vanish
in this limit. The zero extension is therefore C^∞. This applies to both rho_1 (p=2)
and rho_2 (p=4), and to the ratio function k.

The ratio k(s) = rho_2(s)/rho_1(s) = exp(-(L/s)^4 + (L/s)^2). Setting r = L/s:

    exponent = -r^4 + r^2

For large r (s near 0), -r^4 dominates. Numerically verified (Python):
- r=2: exponent = -12
- r=5: exponent = -600
- r=10: exponent = -9900
- r=20: exponent = -159,600

So k → 0 and rho_1/rho_2 → +∞ as s ↓ 0. This is asymptotic, not a global inequality:
at s = L (r = 1), the exponent = 0 so k = 1; at s = 2L, k ≈ 1.206 > 1. The ordering
rho_2 < rho_1 holds only in a sufficiently small neighborhood of s = 0, as stated in
the claim assumptions.

Numerical confirmation:
- s=2.0: k=1.2062 (rho_2 > rho_1)
- s=1.0: k=1.0000 (rho_2 = rho_1)
- s=0.5: k=6.14×10^{-6} (rho_2 << rho_1)
- s=0.3: k=1.62×10^{-49} (rho_2 << rho_1)

### 2. Smoothness of the forward canonical map

The map h_{12}: H_1 → H_2 is the restriction of the ambient smooth map:

    tilde_h_{12}(u, s, x, y) = (u, s, k(s)x, k(s)y),  k=0 for s≤0.

Since k is smooth and flat at s=0 (Section 1), tilde_h_{12} is C^∞ on all of N. Its
restriction to H_1 satisfies: on H_1 with s>0, the point (u, s, rho_1 cos θ, rho_1 sin θ)
maps to (u, s, k·rho_1 cos θ, k·rho_1 sin θ) = (u, s, rho_2 cos θ, rho_2 sin θ) ∈ H_2.
On s≤0, both the input and output radii are 0. So the restriction is indeed h_{12}.

Therefore pullback of any C_2^∞ function on H_2 through h_{12} is C_1^∞ on H_1:
C_2^∞ ⊆ C_1^∞.

### 3. C^1 obstruction for the inverse: MVT argument (independent reconstruction)

Transport the ambient coordinate x from H_1 to H_2 via the inverse:

    f_1(u, s, θ) = rho_1(s) cos θ  (on s>0),  f_1 = 0  (on s≤0).

**Claim:** f_1 has no locally ambient C^1 extension near the tip of H_2.

**Proof:** Suppose for contradiction that Φ is a C^1 function on an open ambient set
U ⊂ N containing p = (u_0, 0, 0, 0), with Φ|_{H_2 ∩ U} = f_1|_{H_2 ∩ U}.

At fixed u_0 and small s > 0, the points (u_0, s, +rho_2(s), 0) and (u_0, s, -rho_2(s), 0)
both lie on H_2 ∩ U. By the matching condition:

    Φ(u_0, s, +rho_2, 0) = +rho_1(s)
    Φ(u_0, s, -rho_2, 0) = -rho_1(s)

The segment {(u_0, s, x, 0) : -rho_2 ≤ x ≤ rho_2} lies entirely in the ambient space N,
and for s small enough, entirely in U. Apply the one-variable mean-value theorem to
the function x ↦ Φ(u_0, s, x, 0): there exists ξ_s with |ξ_s| < rho_2(s) such that

    ∂_x Φ(u_0, s, ξ_s, 0) = [rho_1(s) - (-rho_1(s))] / [rho_2(s) - (-rho_2(s))]
                            = rho_1(s) / rho_2(s).

As s ↓ 0, ξ_s → 0 (since |ξ_s| < rho_2(s) → 0), so (u_0, s, ξ_s, 0) → p.
Since Φ ∈ C^1 on U, the function ∂_x Φ is continuous on U and is bounded on any
compact neighborhood of p. But rho_1(s)/rho_2(s) → +∞. Contradiction.

**Independent verification that the logic is airtight:** The key topological step is
that the ambient segment stays within U for s small enough. This follows because both
endpoints converge to p as s → 0, and U is an open neighborhood of p. The MVT is applied
to the ambient extension Φ, not to a function defined only on H_2; this is crucial and
correct since C_2^∞ precisely requires an ambient extension.

Numerical support:
- s=0.5: rho_1/rho_2 = 1.628×10^5
- s=0.3: rho_1/rho_2 = 6.182×10^{48}
- s=0.2: rho_1/rho_2 = 3.773×10^{260}
- s=0.1: underflows to infinity

### 4. Alternative route: Taylor-coefficient / Fourier analysis attack

(This route is independent of D002 and provides a second proof of the same obstruction.)

If f_1 ∈ C_2^∞(H_2), then it has an ambient C^∞ extension Φ near p. The 1-jet of Φ at p
is Φ ≈ c_u^0 u^0 + c_u^1 u^1 + c_u^2 u^2 + c_s s + c_x x + c_y y + O(|z|^2).

Restricted to H_2 at height s > 0 (with u=0):

    Φ(0, s, rho_2 cos θ, rho_2 sin θ) = c_s s + c_x rho_2 cos θ + c_y rho_2 sin θ + O(rho_2^2 + s^2).

The matching condition f_1 = rho_1(s) cos θ requires this to equal rho_1(s) cos θ for
every θ at each small s > 0. Extracting the Fourier cos(θ) mode:

    c_x · rho_2(s) = rho_1(s)  ⟹  c_x = rho_1(s)/rho_2(s).

But c_x is a fixed real number, independent of s. The right side → +∞ as s ↓ 0.
Contradiction. Therefore f_1 ∉ C_2^∞.

This is a strictly different argument from the MVT (it uses Fourier extraction rather
than a line-segment application of the intermediate value theorem), and reaches the
same conclusion.

### 5. Strict chain of algebra inclusions (both inclusions)

**C_2^∞ ⊊ C_1^∞ (strictly):**
- C_2^∞ ⊆ C_1^∞: shown in Section 2 (forward ambient extension).
- Strict: f_1 = rho_1(s) cos θ is the restriction of the ambient coordinate x to H_1,
  hence f_1 ∈ C_1^∞. By Sections 3–4, f_1 ∉ C_2^∞. So the inclusion is strict.

**C_1^∞ ⊆ C_q^∞:**
Any C_1^∞ function is the restriction of a smooth ambient function Φ to H_1. Its
pullback via F_1 to M is Φ(u, s, rho_1(s) cos θ, rho_1(s) sin θ), which is smooth on M.
For s ≤ 0, rho_1 = 0, so the pullback is Φ(u, s, 0, 0), independent of θ. Therefore
the pullback satisfies the quotient-smooth condition (fiber-constancy on s ≤ 0), giving
C_1^∞ ⊆ C_q^∞.

**C_1^∞ ⊊ C_q^∞ (strictly):**
Define rho_0(s) = ell·exp(-L/s) for s > 0, zero for s ≤ 0. This is C^∞ and flat at
s = 0. The function f_0 = rho_0(s) cos θ is smooth on M and fiber-constant on s ≤ 0,
hence f_0 ∈ C_q^∞.

If f_0 ∈ C_1^∞, it would have an ambient C^1 extension Φ_0 near the tip of H_1. The
same MVT (or Fourier) argument gives:

    ∂_x Φ_0 at some point = rho_0(s)/rho_1(s) = exp((L/s)^2 - L/s)

For large r = L/s: exponent = r^2 - r → +∞. Numerical check:
- s=0.5: rho_0/rho_1 = 7.389
- s=0.3: rho_0/rho_1 = 2.387×10^3
- s=0.1: rho_0/rho_1 = 1.220×10^{39}

This diverges, so f_0 ∉ C_1^∞. Therefore C_1^∞ ⊊ C_q^∞.

The full strict chain is confirmed: C_2^∞ ⊊ C_1^∞ ⊊ C_q^∞.

### 6. Sub-diffeology plot test (independently constructed)

Give H_2 the sub-diffeology induced from N. Construct the following smooth ambient
curve parameterized by t (with [t] = length = [s]):

    s(t) = t,  t ∈ R
    (x(t), y(t)) = (rho_2(t)·cos Θ(t), rho_2(t)·sin Θ(t))  for t > 0
    (x(t), y(t)) = (0, 0)  for t ≤ 0
    Θ(t) = exp((L/t)^3)  for t > 0

**This curve is a smooth ambient-subspace plot in H_2:** For each n, the n-th derivative
of rho_2(t)·cos Θ(t) involves products of powers of t^{-1} and exp(n(L/t)^3) (from
differentiating cos Θ), multiplied by rho_2(t) = ell·exp(-(L/t)^4). Since the quartic
-(L/t)^4 in the exponent dominates the cubic n(L/t)^3 for large L/t, every product
vanishes as t ↓ 0. The zero extension is smooth at t=0.

**Numerical verification that Θ(t) grows rapidly:**
- t=0.5: Θ'(t) = 3L^3 t^{-4} exp((L/t)^3) ≈ 1.43×10^5
- t=0.4: Θ'(t) ≈ 7.16×10^8
- t=0.3: Θ'(t) ≈ 4.50×10^{18}
- t=0.25: Θ'(t) ≈ 4.79×10^{30}

**Under h_{12}^{-1}, the image in H_1 has the same angle Θ(t) but radius rho_1(t).** The
angular component of the velocity is:

    rho_1(t)|Θ'(t)| = 3 ell L^3 t^{-4} · exp(-(L/t)^2 + (L/t)^3)

The exponent -(L/t)^2 + (L/t)^3 → +∞ as t ↓ 0 (cubic dominates quadratic). Numerically:
- t=0.5: speed component ≈ 2.62×10^3
- t=0.4: speed component ≈ 1.38×10^6
- t=0.3: speed component ≈ 6.73×10^{13}
- t=0.25: speed component ≈ 5.39×10^{23}

The image curve is not C^1. Therefore the inverse h_{12}^{-1} fails to be smooth for
the ambient sub-diffeologies of H_1 and H_2.

**Additional observation:** The curve Θ(t) = exp((L/t)^3) does not have a smooth lift
through the quotient map q at t=0 (Θ'(t) → ∞, so no smooth angle function exists).
This confirms that the ambient sub-diffeology on H_2 and the final quotient diffeology
are genuinely different structures, as stated in D002 §4.4.

### 7. Legal base-reparametrization attack (independent analysis)

**Attack:** Can a smooth equivariant base diffeomorphism φ: I → I with φ(0) = 0,
φ'(0) > 0 make both directions of the horn map smooth?

**Analysis:** An equivariant map covering φ has radial multiplier:

    rho_2(φ(s)) / rho_1(s) = exp(-(L/φ(s))^4 + (L/s)^2)

For smoothness in BOTH directions, this multiplier must converge to a positive
finite constant as s ↓ 0; otherwise either the forward map or the inverse has a
diverging/vanishing multiplier, preventing a smooth ambient extension.

If φ(s) = a·s + O(s^2) for some a > 0, then L/φ(s) ~ r/a where r = L/s → ∞.
The exponent becomes -(r/a)^4 + r^2 = -r^4/a^4 + r^2 → -∞.

For any choice of positive leading coefficient a, the quartic term dominates.
Higher-order corrections to φ do not change the leading behavior since they
contribute lower-order terms in r.

**Can the obstruction be repaired by sub-leading corrections to φ?** We need:
    (L/φ(s))^4 - (L/s)^2 → finite constant.
Setting u = L/φ(s) and v = L/s (with v → ∞), this requires u^4 ~ v^2, i.e.,
u ~ v^{1/2}. So φ(s) = L/u ~ L/v^{1/2} = L·sqrt(s/L) = sqrt(L·s).

**Circumference-matching map:** If we require rho_2(φ(s)) = rho_1(s):
    exp(-(L/φ(s))^4) = exp(-(L/s)^2)
    ⟹ φ(s)^4 = L^2 s^2
    ⟹ φ(s) = sqrt(L·s)

Then φ'(s) = sqrt(L)/(2 sqrt(s)) → ∞ as s ↓ 0. Not a smooth diffeomorphism.

Numerically:
- s=0.5: φ'(s) = 0.707
- s=0.1: φ'(s) = 1.581
- s=0.01: φ'(s) = 5.000
- s=0.001: φ'(s) = 15.811  (diverging)

**Conclusion:** No smooth equivariant base diffeomorphism of the declared form repairs
the canonical comparison. The claim's restriction to the canonical comparison (preserving
the normal coordinate and circle label) is essential and correctly scoped.

## Falsification attempts

1. **Global ordering attack:** Verified numerically that rho_2 < rho_1 is NOT a global
   inequality on (0, ε): at s = 2L, k ≈ 1.206 (rho_2 > rho_1). At s = L, k = 1 exactly.
   The ordering is asymptotic near s = 0. The ledger wording explicitly restricts to this
   limit. No falsification achieved; the claim is correctly qualified.

2. **Dimensional attack:** All exponent arguments are (L/s)^p with [L/s] = dimensionless.
   Profile ratios rho_i/rho_j are dimensionless. The MVT derivative ∂_x Φ has dimensions
   [rho_1]/[x] = length/length = dimensionless. No dimensional inconsistency found. PASS.

3. **MVT-path attack:** Attempted to invalidate the MVT by noting the segment might leave
   U. For small s, both endpoints converge to p, and since U is open and contains p, the
   entire segment is in U for sufficiently small s. The MVT argument is topologically
   valid. No falsification achieved.

4. **Sign attack:** The forward map k = rho_2/rho_1 → 0 (smooth, flat). The inverse map
   multiplier rho_1/rho_2 → +∞ (diverges). The asymmetry is exact and has the correct sign.
   A smooth extension exists for the flat multiplier, not for the diverging one. No sign
   error in C008. PASS.

5. **Normalization (2π) attack:** The 2π factor appears in circumference (2π rho_i) and
   Fourier averaging (1/2π), but not in the ratio rho_1/rho_2 or the MVT derivative.
   No normalization error affects the C008 argument. PASS.

6. **Abstract diffeomorphism attack:** Sought a non-equivariant, non-canonical abstract
   homeomorphism H_1 → H_2 that might be a diffeomorphism. C008 explicitly does not
   claim to rule this out; its scope is the canonical comparison preserving (u, s, θ).
   The claim is correctly and explicitly scoped; this is not a gap. No falsification.

7. **Taylor-coefficient counterexample attempt:** Tried to construct a C^1 ambient
   extension by allowing nonlinear terms (higher-order monomials in x, y, s). But the
   leading Fourier matching forces c_x = rho_1/rho_2 independently of higher-order terms
   (which contribute O(rho_2^2) corrections, negligible compared to the rho_2-linear
   term as s → 0). The argument survives. No falsification achieved.

8. **Alternative profile pair attack:** Asked whether the result is special to exponents
   2 and 4, or holds more generally. For any pair of exponents 0 < p < q, the ratio
   exp(-(L/s)^q + (L/s)^p) → 0 as s ↓ 0 (higher power dominates), so the forward map
   is always smooth and the inverse always diverges. The result is general for any
   distinct exponent pair, not a special feature of (2, 4). This strengthens the claim.

9. **Hadamard angular-mode argument (quotient derivation dimension):** Independently
   verified: any quotient-smooth germ g at the interface has angular remainder h = g - ḡ
   satisfying h = 0 for s ≤ 0. By Hadamard division, h = s·k with smooth k; since
   s ∈ m_q and k = 0 at s=0 gives k ∈ m_q, we have h ∈ m_q^2. The first-order
   quotient cotangent space m_q/m_q^2 has dimension 4 (three u-directions plus s).
   Independently confirmed. This underpins the strictness C_1^∞ ⊊ C_q^∞.

10. **Ambient-restriction ideal attack (ambient derivation dimension):** Independently
    verified: any ambient smooth germ Φ vanishing on H_i at the tip p satisfies
    ∂_u Φ = ∂_s Φ = 0 (from the negative s-axis), and ∂_x Φ = ∂_y Φ = 0 (from the
    antipodal pairs on H_i for s > 0 via MVT). So the vanishing ideal I_i ⊂ m_A^2.
    Therefore the cotangent quotient m_{A/I_i}/m_{A/I_i}^2 ≅ m_A/m_A^2, dimension 6.
    Independently confirmed.
