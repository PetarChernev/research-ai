## Reconstruction

### 1. Fibers and homeomorphism (Sub-claim 1)

**Alternative Method 1 (local sections):**

For s > 0: rho_i(s) > 0. The map F_i: M -> N sends (u, s, theta) to (u, s, rho_i cos theta,
rho_i sin theta). At any fixed (u, s) with s > 0, the map theta -> (rho_i cos theta, rho_i sin theta)
is injective on [0, 2pi) and has image the circle of radius rho_i. Thus different theta values
give different points in H_i, so F_i on the s > 0 fiber is injective. The inverse is the
continuous angle-extraction map.

For s <= 0: rho_i(0) = 0 (both profiles are C^inf flat at 0, vanishing there and for s < 0).
All (u, s, theta) for different theta map to the same (u, s, 0, 0) in N.

Therefore the fibers of F_i are exactly the equivalence classes of the relation ~. By the
universal property of quotient topologies, there is a unique continuous bijection
bar_F_i: X -> H_i with F_i = bar_F_i composed with q.

For continuity of the inverse: on the s > 0 open stratum, bar_F_i is a local homeomorphism
(angle extraction from a nonzero circle is a smooth diffeomorphism). On the s < 0 stratum,
bar_F_i is the identity on the (u, s) base and trivially invertible. Continuity at the cone
tip (s = 0) holds because: if (u_n, s_n, x_n, y_n) -> (u_0, 0, 0, 0) in H_i, then since
|x_n^2 + y_n^2|^{1/2} = rho_i(s_n) -> 0 and s_n -> 0, the preimage q(u_n, s_n, theta_n)
converges to q(u_0, 0, -) in X by the quotient topology.

**Alternative Method 2 (properness, reproduced by this verifier):**

F_i^{-1}(K) subset pr_B(K) x S^1 for any K compact in H_i. Since H_i -> B (projection) is
continuous, pr_B(K) is compact. S^1 is compact. F_i^{-1}(K) is closed in this compact product,
hence compact. So F_i is proper. A proper continuous map from locally compact Hausdorff M
to the Hausdorff locally compact H_i (closed subset of Euclidean N) is closed and surjective,
hence a quotient map. The fiber factorization diagram then shows bar_F_i^{-1}(V) is open iff
F_i^{-1}(V) is open iff V is open; so bar_F_i^{-1} is continuous.

**CONFIRMED: Both methods give sub-claim 1.**

### 2. Stratum dimensions (Sub-claim 2)

X_5 = q{s > 0}: The quotient relation collapses nothing for s > 0 (the equivalence class of
(u, s, theta) is just {(u, s, theta)} for s > 0). So X_5 is homeomorphic to U x (0, eps) x S^1,
which is a 5-manifold (dim = 3 + 1 + 1 = 5).

X_4 = q{s < 0}: For s < 0, all angles (u, s, theta) for theta in S^1 are identified to the
single class {(u, s, -): all theta}. So X_4 is homeomorphic to U x (-eps, 0), a 4-manifold
(dim = 3 + 1 = 4).

Sigma = q{s = 0}: For each u in U, all (u, 0, theta) are identified. Different u values are
NOT identified (the equivalence relation preserves u). So Sigma is homeomorphic to U, a
3-manifold (dim = 3).

**CONFIRMED: Sub-claim 2 is correct.**

### 3. Cone neighborhood model (Sub-claim 3)

Fix sigma_0 = q(u_0, 0, theta_0) in Sigma. Define the map

   phi: U' x C_delta(S^1 disjoint_union {*}) -> X

where U' is a small u-neighborhood of u_0, C_delta is the truncated open cone (quotient of
(S^1 disjoint_union {*}) x [0, delta) by the relation that collapses (-, 0) to a single tip),
and phi is defined by:
- phi(u, (r, exp(i*psi))) = q(u, +r, psi) for r > 0 (the S^1 branch)
- phi(u, (r, *))         = q(u, -r, theta_0) for r > 0 (the {*} branch, theta_0 immaterial)
- phi(u, tip)            = q(u, 0, theta_0) (the cone tip)

Continuity: the quotient topology on X makes this continuous because the defining maps
(u, r, psi) -> (u, +r, psi) and (u, r, theta_0) -> (u, -r, theta_0) and the common
limit (u, 0, -) are all continuous relative to the quotient.

Bijectivity: the two branches and the tip are disjoint subsets of X (different s-sign),
and the map is injective on each branch by s-sign separation and on each branch by the
standard circle/point parametrization.

Continuity of inverse: follows from the homeomorphism of the bars (local sections in s).

The uniform cone radius: for a fixed u, the compactness of S^1 ensures that a neighborhood
saturated with respect to the circle can be taken uniformly in theta. Therefore a product
neighborhood U' x C_delta exists. The R^{1,2} factor is topological (the Lorentzian
signature does not affect topological content).

**CONFIRMED: Sub-claim 3 (cone neighborhood model) is correct.**

### 4. Local covering dimension = 5 (Sub-claim 4)

**Alternative proof using cone dimension theorem:**

The link is L = S^1 disjoint_union {*}. By the disjoint union formula for covering dimension
of metric spaces: dim L = max(dim S^1, dim {*}) = max(1, 0) = 1.

For compact nonempty metric spaces X, the covering dimension of the open cone satisfies
dim C(X) = dim X + 1 (this is a standard theorem; e.g., Pears, Dimension Theory of General
Spaces (1975), Chapter 6). Therefore dim C(L) = 1 + 1 = 2.

By the product theorem for separable metrizable spaces:
dim(R^{1,2} x C(L)) = dim(R^3) + dim(C(L)) = 3 + 2 = 5.

**Alternative proof using closed-sum theorem (as in D002):**

C(L) = C(S^1) union C({*}) with shared tip only.
C(S^1) = closed 2-disk, dim = 2.
C({*}) = closed ray [0, delta), dim = 1.
A intersect B = {tip}, dim = 0.
Closed-sum theorem (metrizable spaces): dim(A union B) <= max(dim A, dim B) = max(2, 1) = 2.
Lower bound: dim C(L) >= dim C(S^1) = 2 (monotonicity for closed subsets).
So dim C(L) = 2. Product with R^{1,2}: dim = 3 + 2 = 5.

**Lower bound check:** Every neighborhood of an interface point contains a homeomorphic
copy of the product of a 3-cube (from U) with a closed 5-cell (from the S^1 branch of the
cone plus a normal interval). A closed 5-cell has covering dimension 5. Monotonicity for
closed subspaces of metrizable spaces gives lower bound 5.

**CONFIRMED: Local covering dimension = 5 (Sub-claim 4). Two independent methods agree.**

### 5. Quotient-algebra derivation dimension = 4 (Sub-claim 5, part A)

At an interface point p = q(0, 0, theta_0), the local quotient-smooth algebra C_q^inf
consists of germs of C^inf functions on U x I x S^1 that are theta-independent for s <= 0.

**Independent derivation via cotangent space m_q/m_q^2:**

Let m_q be the maximal ideal of quotient-smooth germs vanishing at p.
Any g in C_q^inf can be uniquely written as g = g_bar + h where
  g_bar(u, s) = (1/2pi) integral_0^{2pi} g(u, s, theta) dtheta (angular average),
  h = g - g_bar (angular remainder, zero average).

Since g is theta-independent for s <= 0, h = 0 for s <= 0. By Hadamard division:
h = s * k for smooth k (on U x I x S^1). Since h = 0 for s <= 0 and s is nonzero for s < 0,
we have k = 0 for s < 0, hence k(u, 0, theta) = 0 by continuity. So k(p) = 0, meaning k in m_q.
Since s(p) = 0, also s in m_q. Therefore h = s * k in m_q^2.

In m_q/m_q^2, only g_bar contributes. The Taylor expansion of g_bar at u=0, s=0 gives:
[g - g(p)] = sum_{alpha=0}^2 (partial_{u^alpha} g_bar)(0)[u^alpha] + (partial_s g_bar)(0)[s]
             in m_q/m_q^2.

The four linear functionals d_{u^0}, d_{u^1}, d_{u^2}, d_s are linearly independent
(d_{u^alpha}(u^beta) = delta_{alpha,beta}, d_s(s) = 1, d_s(u^alpha) = 0, d_{u^alpha}(s) = 0).
So dim(m_q/m_q^2) = 4, hence dim Der_p(C_q^inf, R) = 4.

**CONFIRMED: Quotient derivation dimension = 4 (Sub-claim 5, part A).**

### 6. Ambient-embedding derivation dimension = 6 (Sub-claim 5, part B)

At the tip p = (0, 0, 0, 0) in H_i (which is the image of (u_0=0, s_0=0, theta_0) in Sigma),
the local ambient-restriction algebra C_i^inf consists of restrictions of C^inf germs on
N = U x I x R^2 to H_i.

The restriction ring is A / I_i where A = C^inf(N, p) and I_i is the ideal of germs
vanishing on H_i. The derivation dimension = dim(m_{H_i}/m_{H_i}^2) = dim(m_A/(m_A^2 + I_i)).

**Independent claim: I_i subset m_A^2 (no nonzero linear term).**

For any Phi in I_i (vanishing on H_i):
- Along the ray {(0, t, 0, 0) : t <= 0} in H_i: Phi(0, t, 0, 0) = 0 for t <= 0,
  so partial_s Phi(p) = 0.
- Along the ray {(e_alpha * t, 0, 0, 0) : t near 0} in H_i (using e_alpha for u-directions):
  Phi = 0 on this ray (it lies in {s=0, x=y=0} subset H_i), so partial_{u^alpha} Phi(p) = 0.
- For small s > 0: Phi(0, s, +rho_i(s), 0) = 0 and Phi(0, s, -rho_i(s), 0) = 0.
  The mean-value theorem on the segment x in [-rho_i(s), +rho_i(s)] gives xi_s with
  partial_x Phi(0, s, xi_s, 0) = 0. Since |xi_s| < rho_i(s) -> 0 as s -> 0,
  taking the limit gives partial_x Phi(p) = 0.
- Analogously for y using the y-axis pair: Phi(0, s, 0, +rho_i(s)) = 0 and
  Phi(0, s, 0, -rho_i(s)) = 0 gives partial_y Phi(p) = 0.

All six first-order partial derivatives of any Phi in I_i vanish at p. Therefore I_i subset m_A^2.

The horn equation f = x^2 + y^2 - rho_i(s)^2 is in I_i. Its differential at p has:
  df/du^alpha = 0, df/ds = -2 rho_i(0) rho_i'(0) = 0 (since rho_i(0)=0),
  df/dx = 2x|_p = 0, df/dy = 2y|_p = 0.
So df(p) = 0 and f in m_A^2 (consistent with I_i subset m_A^2).

Since I_i subset m_A^2:
  m_{H_i}/m_{H_i}^2 = m_A/(m_A^2 + I_i) = m_A/m_A^2 = R^6.
The six classes [u^0], [u^1], [u^2], [s], [x], [y] are all nonzero and independent.

**CONFIRMED: Ambient-embedding derivation dimension = 6 (Sub-claim 5, part B).**

## Falsification attempts

The following attacks were systematically attempted. All failed to falsify C007.

**FA1 (Compactness/properness attack):** Attempted to find compact K in H_i such that
F_i^{-1}(K) is not compact by using sequences near s = +/-epsilon or the u-slab boundary.
A compact K in H_i (which is a closed subset of the open N) cannot accumulate at a boundary
of N without a limit point in K; therefore pr_B(K) is compact in B = U x I. The argument
survives. FAILED.

**FA2 (Non-Hausdorff/non-closed image attack):** Checked whether H_i could have limit points
outside itself. H_i = {(u,s,x,y): x^2+y^2 = rho_i(s)^2} is the zero set of the continuous
function (u,s,x,y) -> x^2+y^2 - rho_i(s)^2 in the open set N; hence H_i is relatively closed
in N and is Hausdorff. FAILED.

**FA3 (Wrong fiber attack):** Attempted to find s > 0 such that rho_i(s) = 0 (which would
over-identify points on the positive branch). Both rho_1 = ell*exp(-(L/s)^2) and
rho_2 = ell*exp(-(L/s)^4) are strictly positive for s > 0 (ell > 0, exponential is positive).
FAILED.

**FA4 (Link topology attack):** Attempted alternative links: only S^1 (loses the negative
ray), interval S^0 disjoint {*} (wrong topology), or S^2 (too high-dimensional). The negative
branch contributes exactly one collapsed point per u, giving a ray in the normal direction.
The positive branch contributes a full circle per u. The disconnected link S^1 disjoint {*}
is the unique correct link. FAILED.

**FA5 (Covering dimension attack, upper bound):** Attempted to argue that dim > 5 by claiming
hidden dimensions. The closed-sum formula gives exactly 5 as the maximum. Alternatively,
the cone formula dim C(L) = dim L + 1 = 1 + 1 = 2, and dim(R^3 x C(L)) = 3 + 2 = 5.
Both approaches confirm 5. FAILED.

**FA6 (Covering dimension attack, lower bound):** Attempted to argue dim < 5 at the interface
by noting the interface stratum has dim 3. But every interface neighborhood contains a closed
5-dimensional piece from the positive-s branch. Monotonicity for covering dimension gives
lower bound 5. FAILED.

**FA7 (Hidden quotient angular direction):** Attempted to construct a derivation from an
angular Fourier mode such as sin(theta) or cos(theta), arguing that these distinguish distinct
quotient-smooth germs. For s > 0, such functions are quotient-smooth. But at the interface
point, such a function h(u, s, theta) satisfies h = 0 for s <= 0. Hadamard division gives
h = s*k with k in m_q. So h in m_q^2 and contributes no derivation direction. FAILED.

**FA8 (Hidden ambient linear relation from horn equation):** Attempted to find a nonzero
linear functional in I_i by differentiating the horn equation. The differential of
f = x^2 + y^2 - rho_i(s)^2 at p = (0,0,0,0) is df = 2x dx + 2y dy - 2rho_i rho_i' ds,
all evaluated at p giving df(p) = 0. The horn equation gives no linear relation.
Also checked: the axis-pair MVT argument rules out any linear relation in I_i completely.
FAILED.

**FA9 (Alternative linear relations in I_i):** Tried to construct other elements of I_i
with nonzero first-order part, e.g., functions that vanish on the horn but have nonzero
gradient at p. The axis tests (u^alpha, s, x, y axes) show all partial derivatives of any
I_i element vanish at p. No such function exists. FAILED.

**FA10 (Quotient cotangent space dimension attack):** Tried to find a 5th derivation direction
in Der_p(C_q^inf, R) by looking for angular directions. The averaging argument shows that
any quotient-smooth function's angular part lies in m_q^2. The base (u, s) space is
4-dimensional and supplies exactly 4 derivation directions. FAILED.

**FA11 (Dimensional analysis attack):** Checked all exponents and ratios. Profile exponents
(L/s)^p are dimensionless ([L]/[L])^p. The ratio k = rho_2/rho_1 is dimensionless. The
MVT derivative partial_x Phi ~ rho_1/rho_2 is dimensionless (ratio of lengths). The
circumference 2pi*rho_i has dimension L. All checks pass. FAILED.

**FA12 (Wording attack - interface vs. neighborhood):** The prior OpenAI verification report
(C007-2026-08-19.md, Finding 1) raised the concern that the ledger wording could be read
as saying the interface Sigma itself is locally homeomorphic to R^{1,2} x C(L), which would
be false (Sigma has dim 3, the product has dim 5). Independent assessment: the C007 wording
says "a neighborhood in X of each interface point is locally homeomorphic to...". This is
unambiguous — a neighborhood in X contains the interface point as a point where Sigma meets
the cone tip, not as a point in the interior. The wording is acceptable. The prior concern
is noted but does not constitute a finding requiring correction. FAILED (as a falsification
of the claim; the wording is correct).

**FA13 (Profile ordering global vs. local):** Numerically confirmed: k(s) = rho_2/rho_1 > 1
for s > L (e.g., at s = 2L, k ~ 1.21), so rho_2 > rho_1 is not a global ordering. The
homeomorphism argument does not depend on the relative ordering of the profiles (any positive
rho_i defines a valid homeomorphism). The ordering affects the C008 smooth-structure claim
(which correctly restricts to the asymptotic limit), not C007. FAILED (as attack on C007).

**FA14 (Category/convention attack):** Attempted to argue that using "derivation dimension"
without specifying the smooth category is ambiguous. The C007 claim explicitly names three
separate notions: "local covering dimension," "quotient-algebra derivation dimension," and
"ambient-embedding derivation dimension." D002 (§§4.1-4.3) explicitly defines each. No
ambiguity in the claim as stated. FAILED.
