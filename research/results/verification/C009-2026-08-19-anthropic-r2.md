### 1. Kernel-pair structure and equalizer identification

The equivalence relation (D002 eq 3) is:

```
(u,s,theta) ~_q (u',s',theta')  <=>  u=u', s=s', and
  [ theta = theta' mod 2pi   if s>0 ]
  [ no condition on theta    if s<=0 ]
```

The categorical fiber product (kernel pair) is:

```
R_q = M x_X M = {(u,s,theta1; u,s,theta2)} with:
  R_q|_{s>0}  = diagonal {(u,s,theta; u,s,theta)}
  R_q|_{s<=0} = full fiber {(u,s,theta1; u,s,theta2): all theta1,theta2}
```

Projections: p1(u,s,theta1,theta2) = (u,s,theta1), p2(u,s,theta1,theta2) = (u,s,theta2).

**Equalizer = actual quotient complex (independent proof):**

For the final quotient diffeology on X = M/~_q, every plot P: O -> X locally lifts to
a smooth map P_tilde: V -> M with P|_V = q ∘ P_tilde. This is definitional.

Given an equalizing k-form alpha on M: define on each local lift V by P_tilde* alpha.
On an overlap of two lifts P_tilde1, P_tilde2, the pair (P_tilde1, P_tilde2) is a local
plot of R_q (by the fiber-product diffeology). The equalizer condition p1* alpha = p2* alpha
forces P_tilde1* alpha = P_tilde2* alpha on the overlap. Hence the local forms glue to a
well-defined diffeological form on X.

Conversely, any quotient-diffeological form beta on X pulls back via q to q* beta on M, and
q* beta satisfies the equalizer because for any (m1,m2) in R_q:
  p1*(q* beta) = (q ∘ p1)* beta = q_K* beta = (q ∘ p2)* beta = p2*(q* beta).

Therefore: Omega^k_{diff}(X) = Eq(Omega^k(M) ==> Omega^k(R_q)).

This is **not** merely the subcomplex for the Hector-Macías-Virgós-Sanmartín-Carbón foliation
descent theorem, which requires regular foliation structure; the present kernel pair has jumping
fiber dimension and is not of that type. The local-lift argument works specifically for the final
quotient diffeology and would not hold for an arbitrary diffeology on X.

### 2. Necessary and sufficient one-form conditions

Write a general smooth one-form on M as:

```
alpha = a_mu(u,s,theta) dx^mu + b(u,s,theta) dtheta   [sum over mu = 0,1,2, s]
```

On the full collapsed branch of R_q (s<0), points (u,s,theta1) and (u,s,theta2) are
identified for all theta1, theta2. The fiber product R_q|_{s<0} has tangent space
spanned by {d/du^mu, d/ds, d/dtheta1, d/dtheta2}, where theta1 and theta2 are
**independent coordinates** of the fiber product manifold.

Pulling back:
```
p1* alpha = a_mu(u,s,theta1) dx^mu + b(u,s,theta1) dtheta1
p2* alpha = a_mu(u,s,theta2) dx^mu + b(u,s,theta2) dtheta2
```

These are forms on R_q. Equating them as forms (matching each independent tangent direction):

- Coefficient of dx^mu: a_mu(u,s,theta1) = a_mu(u,s,theta2) for all theta1,theta2.
  => a_mu is theta-independent for s<0.
- Coefficient of dtheta1: b(u,s,theta1) = 0 for all theta1, s<0.
- Coefficient of dtheta2: b(u,s,theta2) = 0 for all theta2, s<0.

These conditions are necessary and sufficient on the open branch s<0. Smoothness of alpha on M
extends these to s=0: since a_mu is theta-independent on the open half-slab s<0 and smooth,
all theta-derivatives of a_mu vanish to infinite order at s=0; similarly b=0 on s<0 forces
all s-derivatives of b to vanish at s=0. The equalizer condition (including at the interface)
is fully captured by:

> **a_mu(u,s,theta) is theta-independent and b(u,s,theta) = 0 for s<=0.**

This is D002 equation (46), independently derived. Condition on s>0: the diagonal kernel
pair imposes no additional constraint there.

### 6. Orbit-quotient vs. principal-bundle basic forms (independent analysis)

The descent condition for the C009 quotient uses the **full kernel pair R_q**, not just
S^1-equivariance. This distinction is critical:

**S^1-equivariance alone (wrong framework for this quotient):**
If we only required p1* alpha = p2* alpha for (u,s,theta1;u,s,theta2) with theta2-theta1 in S^1
(i.e., only the orbit of the vertical action), we would get a LARGER set of forms:
- eta = dtheta + A would pass (it is S^1-equivariant: R_beta* eta = eta)
- This would be the wrong answer because it doesn't match the actual quotient

**Full kernel pair (correct framework):**
R_q|_{s<=0} = all pairs (u,s,theta1;u,s,theta2), NOT just S^1-orbit pairs.
This forces b=0 for s<=0, which eliminates eta. [CORRECTLY IDENTIFIES the form as non-descending]

**Principal bundle "basic form" comparison:**
In principal bundle theory (e.g., Cartan's theory of connections), a form is "basic" if:
(a) horizontal: i(V) omega = 0 for vertical V
(b) equivariant: g* omega = omega for g in G

For the S^1 bundle M -> B = U x I:
- eta = dtheta + A: equivariant (theta-shifts leave eta invariant), but NOT horizontal
  (i(d/dtheta) eta = 1 ≠ 0). Fails horizontality.
- rho_i * eta: equivariant AND horizontal in the principal bundle sense.

Both the principal-bundle basic-form criterion and the kernel-pair equalizer correctly
classify eta as non-descending and rho_i*eta as descending.

But the two frameworks are NOT the same:
- The principal bundle is M -> B = U x I (quotienting by the FULL S^1 action)
- The actual quotient is M -> X = M/~_q (collapsing circles only for s<=0)
- The kernel pair of q is LARGER than the kernel pair of the principal bundle

Using the principal-bundle criterion for the actual quotient q would give wrong answers
for s>0 (it would not let any forms depending on theta survive, but on s>0 the circle
is preserved in X). D002 correctly uses the quotient kernel pair, not the principal bundle
kernel pair. [CONFIRMED - D002's framework is appropriate and correct for this specific quotient]

### 7. Three-way distinction: removed / gauge / forgotten / excluded

D002 and the C009 claim carefully maintain four distinct operations:

1. **Removed by kernel pair:** eta fails the equalizer. Exterior fiber labels are not
   quotient functions. No gauge action, no physical state choice needed; the quotient
   relation itself removes them.

2. **Ordinary gauge (U(1) or Lorentz):** Acts on retained connection data. Preserves F
   exactly (U(1)) or transforms R by conjugation (Lorentz). Cannot erase nonzero curvature.

3. **Exterior forgetful equivalence (Pi_cof or Pi_4):** An explicitly declared kernel
   relation of a projection. Not derived from an action or constraint algebra. Identifies
   configurations that agree on designated retained data but may differ on discarded data.
   Can erase F by declaration (since F is in the discarded sector). NOT ordinary gauge.

4. **Equations or boundary conditions:** A future field equation could force F=0 or K=0
   on solutions. This is dynamical exclusion, not present-state gauge or identity.

The C009 claim correctly states that nonzero F or K "disappear only under" a coframe-only
state (case 3 for F; case 1 for eta), an explicitly enlarged forgetful equivalence (case 3),
or future equations (case 4). It explicitly prohibits calling these "ordinary gauge."

and (A'=chi du^1, F'=chi' ds∧du^1) have identical coframes. Pi_cof identifies them.
Ordinary U(1) does not. The distinction is real and maintained throughout D002. [CONFIRMED]
