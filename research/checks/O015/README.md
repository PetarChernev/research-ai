# O015: Lowest-derivative reduction-action exhaustion

Required exact obligation for C028/D025. `run.py` never writes `result.json`;
only the repository wrapper records a canonical outcome.

## Scope

This checks the purely algebraic exterior-degree-four invariant class generated
by `{eta, epsilon, V, E, K=D_omega V}` with at most one `K`, its sector ranks and
normalized `I0,I1`, and the complete-variation polar coefficient incompatibility
declared in `spec.yaml`.

It does not test physical completeness of the generators; quotient total or
covariant derivatives or integration by parts; construct a jet complex; decide
tangent admissibility; or cover curvature, `DE`, `DK`, two-or-more-`K` actions,
inverse coframes, Hodge operations, extra fields, nonbasic modes, moving
interfaces, functional preservation, or C002/C003.

## Representation and trust-surface assessment

1. **Domain and operations.** The class path represents scalar contraction
   diagrams on four labelled exterior slots. It exhaustively generates metric
   pairings, epsilon contractions, and `V` legs, then uses exact adapted-frame
   evaluation, wedge canonicalization, and rational rank. The dynamics path is
   a sparse graded algebra differentiated from an epsilon expression graph.
2. **Canonical equality.** Integers/`Fraction`, sorted sparse exterior words,
   graded monomials, and exact RREF make equality decidable. There are no
   tolerances, floats, random samples, packages, or heuristic simplifiers.
3. **Quotient.** Only `V^2=1`, `V.K=0`, invariant-tensor identities, and wedge
   antisymmetry are reduced. The domain API rejects an exact/IBP quotient. IBP
   occurs only at variation level and retains its corner.
4. **Arbitrary polynomial V dependence.** Under the invariant-generator premise,
   two epsilons reduce to metric determinants. Extra metric-paired `V`s give
   `V^2=1`; `V.K=0`; repeated `V`s in epsilon vanish; every remaining unpaired
   `V` is explicitly generated as a `V.E` leg. Thus arbitrary powers introduce
   no omitted contraction type.
5. **Why the adapted count is covariant.** Unit spacelike vectors form one local
   SO(1,4) orbit. The runner generates covariant diagrams before evaluating at
   `V=e4`. Its residual tensors are `eta_ab,epsilon_abcd`, and `K` is transverse.
   Equivariant scalar relations at this representative transport around the
   orbit, so this is a counting gauge rather than a restriction of the class.
6. **Trusted analytic premise.** The script does not prove that defining-
   representation invariants of orientation-preserving SO(1,4) are generated by
   `eta` and `epsilon`, with two epsilons reducible to a metric determinant.
   That invariant-theory statement—and physical completeness of the selected
   field generators—remains trusted.
7. **Trust surface.** Only standard-library arithmetic and short claim-local
   diagram, sparse-algebra, graph, derivative, and RREF routines are trusted.
   Reusing O014 would import correlated semantics; reusable infrastructure or a
   CAS would enlarge rather than reduce the surface.
8. **Controls.** Eta-only and `V.E` candidates are generated, not omitted. A
   two-`K` boundary sector must have rank greater than one. The ordered polar
   path does not call the rank path. Fresh children mutate pair order, fiber
   sign, coframe variation, `delta K`, Noether grading, and the domain API. In
   the last child the domain is substantively corrupted to accept the forbidden
   exact/IBP quotient; the unchanged positive assertion requiring API rejection
   then fails. No forced-false sentinel is used.

The implementation producer is `openai/gpt-5.6-sol`. Root orchestration
infrastructure also records `openai/gpt-5.6-sol`; Engineer did not contribute.

## Method and exact outputs

Each sector generates ten eta/V involution diagrams plus one epsilon diagram.
The independent-variation root is

`lambda*epsilon(V,E,E,E,E)/24 + gamma*epsilon(V,K,E,E,E)/6`,

with `delta K=D(delta V)+delta omega V`. A separate polar assembly uses
`V=e4`, `K3=-c dtheta`, `Pi43=-oSigma/2`, `Pi34=+oSigma/2`, both pair orders,
and formal `tau=2*pi`. Expected rows are

- `tau*(kappa5_inv-gamma)` (mixed 43),
- `-3*tau*gamma*c` (common triad rescaling),
- `tau*lambda` (transverse E),
- zero transverse V and zero basic corner pullback.

Observation JSON distinguishes the sparse algebra's **theta-first canonical
order** from the geometric **fiber-right order**. Thus the positive sparse
coefficient `gamma*c*theta*x0*x1*x2` is serialized separately from the
fiber-right geometric action `-gamma*c*oSigma*dtheta`; the latter is consistent
with `I1=-c*oSigma*dtheta`.

For `c>0`, finite nonzero `kappa5`, mixed cancellation requires
`gamma=kappa5_inv`, whereas rescaling stationarity requires `gamma=0`; the
transverse row separately requires `lambda=0`.
